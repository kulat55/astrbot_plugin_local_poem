# astrbot_plugin_local_poem · 本地古诗

一个完全离线的 AstrBot 古诗插件：**接对句、考你古诗**。诗库（612 首、2284 联对句）随插件一起打包，不联网、不调 API、不花 token。

## 功能

| 指令 | 作用 |
| --- | --- |
| `/诗接 <一句诗>` | 给上句接出下句，或给下句反推上句，附作者与出处 |
| `/诗考` | 随机抽一联出题考你，等你的下句 |
| `/诗答 <你的下句>` | 交卷，判定对错并给出完整出处 |

### 示例

```
用户：/诗接 床前明月光
机器人：「疑是地上霜」
—— 李白《静夜思》

用户：/诗考
机器人：考你一句：
「白日依山尽」
接下一句，回 /诗答 <你的答案>

用户：/诗答 黄河入海流
机器人：答对啦！
「白日依山尽，黄河入海流」
—— 王之涣《登鹳雀楼》
```

## 数据

- 来源：[chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（最全中华古诗词数据库，MIT 许可）
- 选篇：水墨唐诗、唐诗三百首、千家诗 三个子集
- 加工：繁体转简体（zhconv）、按联切分对句、去重，生成 `data/poems.json` 随包分发
- 数据范围说明：仅包含上述三个选集中出现的诗句；不在范围内的句子（如《使至塞上》"大漠孤烟直"）会提示"不在库中"

## 安装

1. 在 AstrBot 插件市场搜索 `本地古诗`（发布后），或
2. 下载本仓库 zip，在 AstrBot 后台「插件 → 上传安装」，或
3. 将 `astrbot_plugin_local_poem` 文件夹放入 `data/plugins/`，重启或重载

## 依赖

无第三方依赖，纯标准库 + AstrBot API。

## 兼容性

- AstrBot >= 4.29（在 4.29.3 实测通过）
- 平台：aiocqhttp
